# 雪地羽毛球 · 试玩站

[直接开始羽毛球比赛](https://blackcocwhite.github.io/snow-pickle-play/)

网页单人羽毛球：三档 AI、21 分制，可选一局或三局两胜。手动跑位，高远、吊球、平抽与高点杀球；首次落地即判分。手机推荐横屏。

[旧版雪地匹克球](https://blackcocwhite.github.io/snow-pickle-play/pickleball.html) 保留三关巡回赛、八张强化牌与经典对战；原浏览器进度继续可用。

此仓库仅包含构建后的公开试玩页面；新版只在访问者浏览器保存难度和赛制设置。联机与羽毛球成长系统尚未开放。
